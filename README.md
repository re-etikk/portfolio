# Ritik Kumar — Broadsheet Editorial Portfolio

An interactive, vintage broadsheet / newspaper-inspired portfolio blending high-craft typography, editorial layout, and cinematic web animations. Inspired by vintage publications and modern editorial sites like `roberttran.com.au` and `goats.com.pl`.

Live Portfolio of **Ritik Kumar** — Machine Learning / Deep Learning Engineer & Full-Stack Developer.

---

## 🗞️ Features & Highlights

- **Interactive Magnifying Glass Intro**:
  - Starts with an old-world detective/editorial magnifying glass exploring blurred broadsheet newspaper columns.
  - Follows cursor physics, sharpens print beneath the lens, and features an instant skip option.

- **Vintage Broadsheet Visual Architecture**:
  - Classic serif typography (`Source Serif 4`, `Playfair Display`, and `IBM Plex Mono`).
  - Warm weathered newsprint background (`#efe9db`), multi-column editorial grid, fine horizontal/vertical rules, and decorative section badges.
  - **Dynamic Lens Cursor**: Hovering over project cards transforms the cursor into a vintage inspection magnifying glass with `EXHIBIT` label.
  - **Film Noir Filter**: Project previews are rendered in sepia/monochrome film tone with corner masking tape and red circular exhibition stamps.

- **Interactive Two-Column Case File Dossier**:
  - Clicking any project opens a dedicated case file modal modeled after an investigative dossier.
  - Features drop cap narrative stories, authentic `"CASE CLOSED"` red ink stamp, comprehensive `"HOW IT WAS BUILT"` system architecture specifications, and live launch buttons.

## 🚀 Local Setup

To preview or run locally:

```bash
# Clone the repository
git clone https://github.com/re-etikk/portfolio.git

# Navigate to folder
cd portfolio

# Open index.html in your default browser
# On Windows:
start index.html
# On macOS:
open index.html
# On Linux:
xdg-open index.html
```
